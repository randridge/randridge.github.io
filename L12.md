1.  Take an SRS of $n$ PSUs from a population of $N$ PSUs

2.  Measure $y_{ij}$ for **all** $M_i$ SSUs within the $i$th sampled PSU

To estimate the we\...

1.  Calculate the average cluster total across the sampled PSUs:
    $\displaystyle \tbar = \frac{1}{n} \sum_{i\in \S} t_i$

2.  Multiply average by number of PSUs to get a grand total:
    $\displaystyle \thatclus = N \tbar = \frac{N}{n} \sum_{i\in \S} t_i$

3.  Divide by the total number of SSUs to get an overall mean:
    $\displaystyle \ybarclus = \frac{\thatclus}{M_0} = \frac{N\tbar}{M_0}$

4.  Estimate variance with:
    $\displaystyle \widehat{V}(\ybarclus) = \frac{N^2}{M_0^2} \fpcpar \frac{s_t^2}{n}$
    where $s_t^2=\widehat{V}(t_i)$

    $\displaystyle \widehat{V}(\ybarclus) = \frac{1}{M_0^2}\widehat{V}(\thatclus)$

Our mean estimator is:
$$\ybarclus =  \frac{N \tbar}{M_0}  = \frac{\thatclus}{M_0}$$

Note the denominator: total number of SSUs

This is often called the , since it is unbiased for the true population
mean ($\ybar_U$)

-   We have taken an SRS of PSU totals $(t_i)$

-   Thus by property of SRS, the estimated total is unbiased:
    $E[\thatclus] = t_U$

-   Thus
    $E[\ybarclus] = E[\thatclus/M_0]=E[\thatclus]/M_0 = t_U/M_0 = \ybar_U$

The can also be written in terms of the sampling weights:

$$\ybarclus = \frac{\sum_{i\in \S} \sum_{j\in \S_i}  w_{ij} \yij}{M_0}$$

(Remember that when an SRS of PSUs is taken, $w_{ij} = N/n$ for all
sampled units)

But, what if we don't know $M_0$?

We can definitely still estimate the total -- but can we still estimate
the mean?

An alternative estimate is called the :
$$\ybarr = \frac{\thatclus}{\widehat{M}_0} = \frac{N \tbar}{N \Mbarhat} = \frac{N \frac{1}{n} \sum_{i\in \S} t_i}{N\frac{1}{n} \sum_{i\in \S} M_i}  = \frac{\sum_{i\in \S} t_i}{\sum_{i\in \S} M_i} = \frac{\sum_{i\in \S} M_i \ybar_i}{\sum_{i\in \S} M_i}$$
where $\Mbarhat = \frac{1}{n} \sum_{i \in \S} M_i =$ average number of
SSUs per PSU (based on sample)

Note the denominator: total number of SSUs

The can also be written in terms of the sampling weights:

$$\ybarr = \frac{\thatclus}{\widehat{M}_0} = \frac{\sum_{i\in \S} \sum_{j\in \S_i}  w_{ij} \yij}{\sum_{i\in \S} \sum_{j\in \S_i}  w_{ij} }$$

This estimator can be used

It is, however, **not unbiased**

$E[\ybarr] \ne \ybar_U$

It is also a **ratio of two random variables**

Both the numerator, $\thatclus$, and denominator, $\widehat{M}_0$, will
be different in another sample

The bias will be small, however, if the correlation between $M_i$ and
$t_i$ is close to 1\
*(If cluster sizes and cluster totals are highly correlated)*

And, this is usually the case!

Ratio estimate of the mean is than the unbiased estimate -- why?

(Note: this is just true for this sample -- ratio estimator could be
bigger, could be smaller, depends on the specific sample)

So -- why would we want to use a **biased** estimator, even if the bias
is small?

Because of potentially HUGE gains in efficiency -- much smaller variance
estimate

But, it is also a **ratio of two random variables**
$(\thatclus,\widehat{M}_0)$ -- tricky to deal with

To calculate its variance we use Taylor series [^1]

-   We want the variance of a nonlinear function of two random
    variables: $V(\thatclus/\widehat{M}_0)$

-   We cannot "pull apart\" this nonlinear function with rules like
    $V(X+Y) = V(X) + V(Y) + 2\Cov(X,Y)$

-   But, if we could then we **could** use the usual variance rules

-   So, reduces the nonlinear quantity (the ratio, here) to an
    approximate linear quantity by using the linear terms of a Taylor
    series expansion[^2]

-   Then a variance formula can be constructed using usual rules (and an
    estimate obtained by plugging in estimates of unknown quantities)

For our estimate of the mean, $\ybarr$, the first order Taylor series
expansion is:
$$\ybarr = \frac{\thatclus}{\widehat{M}_0} \approx \frac{t_U}{M_0} + \frac{1}{M_0}\left(\thatclus - \frac{t_U}{M_0} \widehat{M}_0 \right)$$

So now the rules of variance of a linear combination of random variables
can be used: $$\begin{aligned}
V(\ybarr) & \approx V\left[\frac{t_U}{M_0} + \frac{1}{M_0}\left(\thatclus - \frac{t_U}{M_0} \widehat{M}_0 \right)\right] \\
&= \frac{1}{M_0^2}\left[V(\thatclus) + \frac{t_U^2}{M_0^2} V(\widehat{M}_0) - 2\frac{t_U}{M_0} \Cov(\thatclus,\widehat{M}_0) \right]
\end{aligned}$$

Note that this variance expression contains both:

-   $\thatclus, \widehat{M}_0$ -- estimates, which are

-   $t_U, M_0$ -- fixed, unknown quantities ()

    -   Thus $t_U$ and $M_0$ can be pulled outside the variance (and get
        squared)

To get the estimated variance, plug in $\thatclus$ and $\widehat{M}_0$
(in place of $t_U$ and $M_0$) in the variance expression above

Looking closer at this variance expression:

$$V(\ybarr) \approx \frac{1}{M_0^2}\left[V(\thatclus) + \frac{t_U^2}{M_0^2} V(\widehat{M}_0) - 2\frac{t_U}{M_0} \Cov(\thatclus,\widehat{M}_0) \right]$$

If the cluster sizes are all the same size:

-   because every sample of $n$ PSUs contains the same number of SSUs

-   because $\widehat{M}_0$ is a constant, and the covariance of a
    random variable with a constant is 0

Thus, the linearization variance estimator reduces to:
$\displaystyle V(\ybarr) = \frac{1}{M_0^2} V(\thatclus)$

which is the variance of the unbiased estimator!

Software (e.g., Stata, R, SAS) is actually using the linearization
estimator even when the clusters are all the same size

Linearization is also used for other, complex statistics -- such as
regression coefficients

By plugging in estimates for the quantities in $V(\ybarr)$, for a where
the , we can the variance of the (ratio estimator of the) mean with:
$$\begin{aligned}
\widehat{V}(\ybarr) &= \frac{1}{n \Mbarhat^2} \fpcpar \frac{\sum_{i \in \S} (t_i - M_i\ybarr)^2}{n-1} \\
&= \frac{1}{n \Mbarhat^2} \fpcpar \frac{\sum_{i \in \S} M_i^2 (\ybar_i - \ybarr)^2}{n-1}
\end{aligned}$$

Notable pieces:

-   $\Mbarhat = \frac{1}{n} \sum_{i \in \S} M_i =$ average number of
    SSUs per PSU (based on sample)

-   FPC = $\fpcpar$ is incorporated (based on number of PSUs)

-   Last piece (with the summation) looks kind of like a variance of
    $t_i$

$\sum_{i \in \S} (t_i - M_i\ybarr)^2$ = how far the PSU totals $(t_i)$
are from the

$M_i \ybarr$ = (size of the PSU) $\times$ (estimated mean) = estimate of
the total for that PSU

Recall the estimated variance of the unbiased estimator:
$$\begin{aligned}
\widehat{V}(\ybarclus) &= \frac{N^2}{M_0^2} \fpcpar \frac{s_t^2}{n} = \frac{1}{n\blue{\bar{M}}^2} \fpcpar \frac{\sum_{i \in\S_i} (t_i - \blue{\tbar})^2}{n-1}
\end{aligned}$$ (second expression from
$s_t^2 = \frac{1}{n-1}\sum_{i \in\S_i} (t_i - \tbar)^2$ and
$\bar{M}=M_0/N=$ true mean number of SSUs per PSU)

$\sum_{i \in\S_i} (t_i - \tbar)^2$ = how far the PSU totals $(t_i)$ are
from the

Compare to the variance of the ratio estimate of the mean:
$$\widehat{V}(\ybarr) = \frac{1}{n \red{\Mbarhat}^2} \fpcpar \frac{\sum_{i \in \S} (t_i - \red{M_i\ybarr})^2}{n-1}$$

Very similar -- but two differences:

-   Ratio estimator uses an estimate of the average number of SSUs per
    PSU $(\Mbarhat)$ where the unbiased estimator uses the actual, true
    average $(M_0/N)$

-   The differences $(t_i - M_i\ybarr)$ for the ratio estimator will be
    than the differences in the unbiased estimator, $(t_i-\tbar)$

    -   Comparing the total for PSU $i$ to a much closer value since the
        size of the PSU $(M_i$) is taken into account!
