Important point:

-   The goal of imputation to perfectly replicate the data value that
    would have been observed

-   The goal of imputation to replace missing values by "plausible\"
    values in order to make use of all available information (i.e.,
    other info we have about a survey respondent) so that is improved
    (relative to discarding missing data)

In general, imputation is for

For **complex sample surveys**, the two most common reasons for imputing
are:

1.  There is missing data on variables (collected on the survey) that
    will be used for weight adjustments (post-stratification, raking,
    etc.)

2.  Key survey outcomes have missingness and we don't want different
    analysts to get different answers

Generally speaking, imputation for both of these reasons will be (e.g.,
CDC) and the imputed data provided to secondary data analysts (often
with imputation "flags\" so you know which values have been imputed)

General benefits of imputation:

-   Potential for gain in efficiency relative to complete case

-   Potential for reduction in nonresponse bias relative to complete
    case

In order to properly treat the imputed data **not** as if it were known,
one common procedure is **multiple imputation**[^2]

It's what it sounds like:

Single Imputation:

:   Replace each missing value with value\
    $\rightarrow$ Create completed data set\
    $\rightarrow$ Analyze that one data set as usual

Multiple Imputation:

:   Replace each missing value with values\
    $\rightarrow$ Create completed data sets\
    $\rightarrow$ Analyze each data set and combine the resulting
    estimates\
    (using so-called "Rubin's Rules\")

Multiple imputation more often used with SRS/convenience samples (e.g.,
observational studies, clinical trials)

Applying multiple imputation in survey context is (more) complicated --
have to properly account for the sample design

Some publicly available surveys do release multiply imputed data -- most
often income data (e.g., NSCH, NHIS) -- why might this be?
