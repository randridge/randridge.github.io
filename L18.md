Not random variables:

-   $y_i$ = survey outcome of interest for unit $i$,

-   $\bm{x}_i$ = vector of information known about unit $i$,\
    (limited to design information, information on the sampling frame,
    or information about the interview process)

Random variables:

-   $Z_i$ = selection indicator for unit $i$ (=1 for sampled units, =0
    for non-sampled units)

    -   $\pi_i = P(Z_i=1)$ = selection probability (known!)

-   $R_i$ = response indicator for unit $i$

    -   $\phi_i = P(R_i=1)$ = probability unit $i$ responds = response
        propensity (unknown)

Three types of missing data mechanisms:

-   : $P(R_i=1 | y_i, \bm{x}_i) = P(R_i=1)$ $\leftarrow$ missingness
    doesn't depend on $y$ or $x$

-   : $P(R_i=1 | y_i, \bm{x}_i) = P(R_i=1|\bm{x}_i)$ $\leftarrow$
    missingness doesn't depend on $y$

-   : $P(R_i=1 | y_i, \bm{x}_i)$ $\leftarrow$ missingness depends on
    $y$, possibly also $x$

If $R_i \indep Z_i$ (response is independent of selection into the
sample), then the probability that unit $i$ will be measured (i.e., will
be sampled and respond) is: $$\begin{aligned}
P(\text{unit }i & \text{ selected in sample and responds}) \\
& = P(\text{unit }i\text{ selected in sample})\times P(\text{unit }i\text{ responds}|\text{unit }i\text{ selected in sample}) \\
& = P(\text{unit }i\text{ selected in sample})\times P(\text{unit }i\text{ responds}) \\
& = \pi_i \phi_i
\end{aligned}$$

We adjust the weights by and then assigning the weights:
$$w_i = \begin{cases} \frac{1}{\pi_i \phihat_i} & \text{for respondents }(R_i=1) \\ 0 & \text{for nonrespondents }(R_i=0)
\end{cases}$$

Simplest weighting adjustment method (but very, very commonly used)

-   Create groups of respondents and nonrespondents based on variables
    observed for both (e.g., frame data, design variables)

    -   These groups are called weighting adjustment

-   Estimate the response probability within each class with either the
    unweighted or weighted response rate in the class $$\begin{aligned}
        \phihat_c &= \frac{\text{\purple{number} of \red{respondents} in class } c}{\text{number of \blue{selected units} in class }c} \\
        \text{or \qquad} \phihat_c &= \frac{\text{\purple{sum of weights} for \red{respondents} in class } c}{\text{sum of weights for \blue{selected sample} in class }c}
        
    \end{aligned}$$

-   Implicitly this assumes probability of response is the

-   Use these estimated response propensities for each class,
    $\phihat_c$, to adjust the weights for the respondents as:
    $$\tw_i = w_i \frac{1}{\phihat_i} = \frac{1}{\pi_i \phihat_i}$$

Note that all weights are since response propensities are between 0 and
1

This is different than (with complete response) where some units get
up-weighted and some down-weighted

More complex weighting adjustments are possible -- fancier methods to
estimate $\phihat_i$

-   Ex: Logistic regression with $R_i$ as the outcome

    -   Predictors are variables available for both respondents and
        nonrespondents (those available for creating classes)

    -   Each respondent has a predicted propensity from the model,
        $\phihat_i$

    -   Adjusted weight is (as usual) $\tw_i = w_i/\phihat_i$

    -   Or -- create classes based on grouping units with similar
        $\phihat_i$

When adjusting the weights for nonresponse, you can think of it as
multiplying each weight by an adjustment factor, where
$$\blue{\tw_i} = \red{w_i} \times \purple{\frac{1}{\phihat_i}} = \red{w_i} \times \purple{\text{(adjustment factor)}}$$
This may remind you of :
$$\blue{w_{hj}^{PS}} = \red{w_{hj}} \times \purple{\frac{\text{Population total in post-stratum}~h}{\text{Estimated total in post-stratum}~h}}  = \red{w_{hj}} \times \purple{\frac{N_h}{\widehat{N}_h}}$$

Weighting adjustments for nonresponse can be :

1.  First, make nonresponse adjustments to the weights

2.  Second, use or to ensure that weights sum to population totals for
    key quantities (for which you know the population totals)

The adjustment factors just all get multiplied together:
$$\tw_i = w_i \times \frac{1}{\phihat_i} \times \frac{N_h}{\widehat{N}_h}$$
where unit $i$ belongs to poststratum $h$

Key difference between nonresponse weight adjustments and
poststratification/raking:

-   For **nonresponse weight adjustments**, you must have the variables
    that create the adjustment cells

-   For **poststratification/raking**, you need the (individual
    nonrespondent data not needed)

Most often, both are done -- nonresponse first, then
poststratification/raking (also commonly called calibration)

Other weight adjustments are commonly done in certain scenarios as well,
e.g.,:

-   **Ineligibility adjustment** -- some sampled units may not be
    eligible (e.g., phone number that does not belong to a person in the
    target population), so adjust weights to reallocate the weights for
    these ineligible units

-   **Dual-frame adjustment** -- for surveys that use two frames (e.g.,
    cell phone frame and landline frame), adjust for the fact that some
    units could appear on both frames and thus have a higher chance of
    selection into the sample

-   **Number of phone numbers adjustment** -- in phone surveys, people
    with more than one phone number have higher probability of selection
    (but don't know who has multiple numbers at the design stage), so
    adjust weights accordingly (higher probability of selection
    $\rightarrow$ lower weight)
